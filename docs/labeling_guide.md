# 라벨링 가이드 — v2 6클래스 (Label Studio)

대상: `data/own/b04_obstacle/raw/` 150장 (`select_frames`로 고름, 근거는 `selection.csv`). 2명이 75장씩
(`prelabel_batch1~2.json`). 창문·외벽은 v1 모델이 미리 그려 둔 것을 **고치고**, 장애물 4클래스는 **새로 그린다**.
Labeling Interface: `cv/facade_cv/detect/datasets/label_studio/labeling_config.xml` (단축키 1~6).

## 공통 규칙
- 모두 **polygon**. 인스턴스 하나 = polygon 하나 (같은 클래스라도 떨어져 있으면 따로)
- 이미지 밖으로 나가는 물체는 이미지 가장자리까지 그린다
- 이미지 긴 변의 약 1%(1920px 기준 ~20px)보다 작은 물체는 그리지 않는다. **전선만 예외** (가늘어도 그림)
- 겹칠 때는 **보이는 그대로**: 앞에 있는 물체(나무·전선·기둥)를 그리고, 뒤의 창문은 아래 "가려진 창문" 규칙
- 확신이 없으면 그리지 말고 Label Studio 댓글에 `?` — 나중에 같이 정한다 (빠진 라벨보다 틀린 라벨이 더 해롭다)

## 클래스별

| 클래스 | 그린다 | 그리지 않는다 |
|---|---|---|
| **window** (1) | 유리창 한 짝 = 한 인스턴스 (창틀 바깥선까지). 커튼·블라인드가 닫힌 창, 방범창 뒤 창, 반사가 심한 창 | 출입문 유리(→ door), 쇼윈도처럼 1층 바닥까지 내려오는 출입 가능한 유리면(→ door), 벽에 붙은 간판·포스터 |
| **facade** (2) | 건물 외벽 전체 외곽 하나 (창문 자리 포함해 바깥선으로). 건물 장식 기둥·처마·난간 벽 포함 | 하늘, 땅, 담장(건물과 떨어진 벽), 다른 건물(그 건물은 따로 facade) |
| **vegetation** (3) | 나무(줄기 포함)·관목·잔디·화단, **벽을 덮은 담쟁이** | 화분 안 작은 화초(< 1%), 벽에 그려진 그림 속 나무 |
| **wire** (4) | 전선·통신선·케이블 한 가닥(또는 붙어 가는 다발) = 한 인스턴스. 2~3px 폭의 가는 polygon으로 선을 따라 | 창문 방범창 살, 빨랫줄 외 건물 일부(배관 → facade) |
| **pole** (5) | 전봇대·가로등·신호등·표지판 **기둥**(땅에 서 있는 독립 기둥) | 건물에 붙은 장식 기둥·필로티(→ facade), 철탑(이번 범위 아님) |
| **door** (6) | 출입문(유리문 포함, 문틀 바깥선까지), 셔터, 쇼윈도형 출입 유리면 | 창문, 창고 환기구 |

## 애매한 사례

| 사례 | 처리 | 이유 |
|---|---|---|
| 담쟁이가 벽을 덮음 | 담쟁이 = **vegetation**. facade는 담쟁이 포함한 건물 외곽 그대로 | 후처리가 "창 마스크 ∩ vegetation"으로 오검출을 지운다 — 담쟁이 위에 창을 그리면 안 된다 |
| 담쟁이 사이로 창이 보임 | 보이는 창은 **window** (전체 사각형), 덮은 담쟁이는 vegetation | 아래 "가려진 창문" |
| 출입문 유리 | **door** (window 아님) | v1 오검출의 대표 사례. 문 위 창은 후처리에서 `on_door`로 제거 |
| 1층 상가 통유리 | 바닥까지 내려오고 출입구가 있으면 **door**, 허리 높이 위만 유리면 **window** | 청소 대상(창)과 출입부를 구분 |
| 얇은 전선 | **wire**. 확대해서 선을 따라 폭 2~3px | 가늘어 보이지 않아도 창 앞을 지나가면 오염 계산을 망친다 (occlusion) |
| 건물 장식 기둥·필로티 | **facade** (pole 아님) | pole은 건물과 떨어진 독립 기둥만. 섞으면 모델이 벽 기둥을 장애물로 배운다 |
| 가로등에 달린 표지판 | 기둥만 **pole**, 판은 그리지 않음 | |
| 가려진 창문 (나뭇가지·전선이 앞에) | window는 **가려진 부분까지 포함한 창 전체 사각형**, 앞 물체는 자기 클래스로 따로 | 창 위치·크기는 격자·3D에 필요. 가린 영역은 후처리가 occlusion으로 빼낸다 |
| 창이 절반 이상 나무에 가려 창틀이 안 보임 | window 그리지 않음, vegetation만 | 보이지 않는 창의 모양을 추측하지 않는다 |
| 유리에 비친 나무·전선 | 그리지 않음 (window만) | 반사는 유리 위 무늬 — 실제 장애물 아님 |
| 사람·차 | 그리지 않음 (배경) | v2 범위 밖 |

## 작업 순서 (1명 기준)
1. Label Studio에서 자기 batch 프로젝트 열기 (task 75개, 예측 polygon이 보임)
2. 예측 window/facade 확인 → 틀린 것 삭제·수정, 빠진 것 추가 (출입문 위에 그려진 window는 door로 라벨 변경)
3. vegetation → wire → pole → door 순으로 새로 그리기
4. Submit. 한 장 평균 4~6분 예상 (전선이 많은 장은 더)
